# Auto Launcher v1.2.0

## 新增

- 新增远程 Web 控制台。
- App 自动生成设备码和设备密钥，设备码可在“权限与系统设置”页查看。
- Web 控制台可查看 App 上报的任务、权限、应用列表和执行日志。
- Web 控制台可远程创建任务、启停任务、添加/删除一次性跳过日期。

## 稳定性

- 手机离线、服务器不可用或控制台不可访问时，已保存任务仍在手机上执行。
- App 每约 30 秒轮询远程命令；命令应用后会立即回写结果。
- 后端使用 SQLite 保存设备状态和待处理操作。

## 升级提示

- 从旧版本升级后，已有本地任务会继续保留。
- 第一次打开新版 App 后，在“权限与系统设置”页查看设备码，再用该设备码登录 Web 控制台。
